__main__.py

1. __name__
    => 현재 파이썬 파일이 어떤 이름으로 실행되고 있는지 알려주는 특별한 변수입니다.
    => 현재 if __name__ == __main__이라면 -> 현재 내 파일 __main__

2. raise SystemExit(main())
    2-1. main을 실행합니다.
    2-2. main 함수가 종료되면 반환값을 SystemExit에 전달합니다.
    2-3. SystemExit은 파이썬에서 프로그램을 종료할 떄 사용하는 예외입니다.
    2-4. raise는 예외를 발생시키는 키워드입니다.
    2-5. 내부적으로 SystemExit 1을 인위적으로 발생시켜 정상종료라는 것을 알립니다.
