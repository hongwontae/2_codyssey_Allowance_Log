1. class Transaction은 가계부에 기록할 거래 내역을 저장하는 객체를 만들 클래스입니다.
    1-1. 클래스의 __init__은 객체를 생성할 떄 필요한 데이터를 받아서 객체의 속성에 저장하는 역할을 합니다.


2. from dataclasses import dataclass
    2-1. @dataclass를 클래스 위에 기재합니다.
    2-2. 그러면 __int__역할을 대체합니다. -> 들어오는 인자에 따라 초기화가 됩니다.
        => 객체의 값 넣어주는 역할
    2-3. tags = 'default' -> 이렇게 기본값을 넣어줄 수 있습니다.


3. 타입 힌트
    => 타입 힌트는 일반적으로 타입을 강제하지는 않습니다.
    => tags: list[str] | None = None -> 타입 힌트와 기본값을 넣어준 형태입니다.
    => tags는 list 내부에 str이 존재 | None 값을 받는데 이 떄 아무것도 없으면 None이다.

4. None
    => 값이 없다는 것을 알려주는 타입이자 객체입니다.
