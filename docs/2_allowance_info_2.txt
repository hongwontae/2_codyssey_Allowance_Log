cli.py

** python main.py -> 이건 default

1. argparse
    => 터미널에서 들어온 명령어를 분석할 수 있도록 규칙을 정하는 라이브러리입니다.


2. def main() -> int:
    => main이라는 함수이고 정수를 반환한다는 타입 힌트가 존재합니다. -> main을 호출한 SystemExit에 정수를 받아야 함


3. parser = argparse.ArgumentParser (...)
    3-1. 사용자가 입력한 명령줄 인자를 분석하는 객체를 생성합니다.
    3-2. prog="budget_app", -> 도움말에 표시할 프로그램 이름
    3-3. description="파일 기반 콘솔 가계부" -> 프로그램에 대한 설명


4. parser.add_argument(...)
    4-1. add_argument는 사용자가 입력할 수 있는 명령줄 인자를 등록하는 메서드입니다.
    4-2. "--data-dir", -> 데이터 저장 폴더를 지정하는 옵션입니다.
    4-3. default="data", -> 사용자가 옵션을 생략하면 data를 기본값으로 사용합니다.
    4-4. help="데이터 저장 폴더 경로 (기본값: data)" -> 도움말에 표시할 설명입니다.
    4-5. python main.py add -> data 사용
    4-6. python main.py --data-dir ./my_data add -> ./my_data 사용
        => 이 떄 폴더를 직접 생성하거나 데이터를 저장하는 것은 아닙니다. 경로를 입력받을 수 있도록 규칙만 등록합니다.


5. subparsers = parser.add_subparsers(...)
    5-1. 하위 명령어를 구성하는 작업입니다.
    5-2. dest="command", -> python main.py delete --id 3 -> args.command == "delete"
    5-4. required=True  -> 하위 명령어를 반드시 하나 선택하도록 합니다.
        = 여기서 하위 명령어들은 add, delete, update, summary, list, search, export, import, category, budget
        => 바로 직속 하위 명령어들만 처리합니다.
        => 하위 명령어들의 옵션까지 건들이지 않습니다. -> 그건 하위 명령어 최상위가 결정합니다.


6. subparsers.add_parser("add", help="거래 추가")
    6-1. add라는 하위 명령어를 등록하는 코드입니다.
    6-2. python main.py add가 가능해집니다. / 실제 거래 추가하는 로직이 없으면 의미가 없습니다.


7. delete_parser = subparsers.add_parser("delete", help="거래 삭제")
    delete_parser.add_argument("--id", required=True, help="삭제할 거래 ID")

    7-1. delete라는 하위 명령어를 생성하고 그 명령어에만 적용되는 --id 옵션을 등록합니다.
    7-2. python main.py delete --id 3 -> 이제 이런 명령어를 유효한 명령어가 됩니다.
    7-3. required 떄문에 --id 옵션의 값은 필수적으로 받아와야 합니다.
    7-4. 위 명령어 결과 args.command == "delete" /args.id == "3" args 객체를 통해 가져올 수 있습니다.


8. update_parser = subparsers.add_parser("update", help="거래 수정")
    8-1. update라는 하위 명령어를 생성합니다.
    
    8-2. update_parser.add_argument("--id",required=True, help="수정할 거래 ID")
        => id 옵션은 true -> 필수
        => python main.py update --id 4 -> 이런 명령어가 유효하게 되고 args_command = "update" / args.id == "4"
    
    8-3. update_parser.add_argument("--date", dest="transaction_date", help="수정할 날짜 (YYYY-MM-DD)")
        => dest 옵션을 사용하면 args.transaction_date로 접근해서 옵션의 값을 가져올 수 있습니다.
        => 즉, 변수명을 지정하는 것입니다.
        => dest 생략시 arts.date로 접근합니다.
    
    8-4. update_parser.add_argument("--type", dest="transaction_type", choices=["income", "expense"], help="수정할 거래 타입")
        => --type 옵션은 income이나 expense만 받아들입니다. -> 다른 값을 주면 오류가 발생합니다.
    
    8-5. update_parser.add_argument("--amount", type=int, help="수정할 금액")
        => type은 사용자가 입력한 옵션 값을 특정 타입으로 변경해줍니다.
        => args.amount -> int 타입입니다.


9. list_parser = subparsers.add_parser("list", help="거래 목록 조회")
    => 최상위 명령어 객체의 바로 아래 하위 명령어를 list로 등록합니다.
    => python3 -m budget_app list -> 가능

    9-1. list_parser.add_argument("--limit", type=int, default=10, help="출력할 거래 개수")
        => default는 사용자가 해당 옵션을 입력하지 않았을 떄 기본값입니다.
    

10. search_parser = subparsers.add_parser("search", help="거래 검색")
    => search를 등록합니다.
