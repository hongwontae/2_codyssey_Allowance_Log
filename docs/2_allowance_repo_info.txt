    1-4. Transaction : 거래 데이터를 표현하는 클래스


2. def __init__
    2-1. 저장소 객체를 만들 떄 파일 경로를 전달받고, 이를 self.file.path에 저장합니다.
        => repository = TransactionRepository(Path("data/transactions.jsonl"))
        => self.file_path는 data/transactions.jsonl 경로를 가리키게 됩니다.
        => self.file_path에는 경로가 존재합니다. -> 이 경로에 맞는 폴더나 파일이 없으면 data/transactions.jsonl 이름이 붙여집니다.
    
    2-2. self.file_path.parent.mkdir (
        parents=True,
        exist_ok=True)
        => 해당 경로의 부모 디렉터리를 가져오는 속성입니다.
        => data 폴더를 의미합니다.
        => mkdir() 디렉터리를 생성합니다.
        => parents=True : 상위 폴더까지 필요한 경우 함께 생성
        => exist_ok=True : 폴더가 이미 있어도 오류를 발생시키지 않고 그냥 넘어갑니다.
        => 즉, data 폴더가 존재하면 2-2는 실행되지 않습니다.
    
    2-3. self.file_path.touch(exist_ok=True)
        => exist_ok=True가 파일이 이미 있어도 오류를 발생시키지 않고 그냥 넘어갑니다.
        => 즉, 파일이 존재하면 2-3은 실행되지 않습니다.

    2-6. with self.file_path.open("r", encoding="utf-8") as file:
        => 파일을 여는 코드입니다.
    
    2-7. for line in file:
            # 빈 줄은 건너뛴다.
            if not line.strip():
                continue
        => 파이썬 파일 객체을 직접 반복하면 파일의 내용을 한 줄씩 읽어줍니다.
        => line은 한 줄 
        => strip은 문자열의 앞 뒤 공백, 줄바꿈 제거 
        => 빈줄 not -> true -> continue -> 빈 줄은 넘기겠다는 의미입니다.

    2-8. data = json.loads(line)
        => line을 파이썬 객체로 변경하겠다는 의미입니다.
    
    2-9. yield Transaction(**data)
        => 기존의 방법이라면 Transaction(
            id=data.id,
            type=data.type,
            date=data.date,
            amount=data.amount,
            category=data.category) 이런 형식으로 줘야 합니다.
        => 그러나 data 한 줄은 저 모양을 갖추고 있습니다.
        => 그리고 line 파이썬 딕셔너리 키가 Transaction의 매개변수와 같고 개수도 같습니다.
        => 이 떄는 Transaction(**data)를 통해 간단하게 객체를 생성할 수 있습니다.
    
    2-9. yield Transaction(**data)
        => yield는 값을 하나 제공한 다음 함수 실행을 잠시 멈추고 다음 값을 요청받으면 멈췄던 지점부터 다시 실행합니다.
