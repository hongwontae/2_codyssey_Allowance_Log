cil.py -> repository 초기화 및 args.command에 따른 연결


1. data_dir = Path(args.data_dir)
    => args.data_dir에 접근하면 --data_dir 옵션의 값을 가져옵니다. 만약 없다면 data입니다.
    => 이 문자열을 토대로 path 객체를 생성합니다.


2. transaction_repository = TransactionRepository( data_dir / "transactions.jsonl" )
    => /은 pathlib.Path에서는 경로를 결합하는 연산자입니다.
    => data_dir = Path("data") print(data_dir / "transactions.jsonl") -> data/transactions.jsonl


3. transaction_service = TransactionService(transaction_repository,category_repository,)
    =>  거래를 추가하거나 수정할 때 카테고리가 실제로 등록되어 있는지 검사해야 하기 때문에 전달해 줍니다.
