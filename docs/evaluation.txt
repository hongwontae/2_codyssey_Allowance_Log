1. 파일 기반 저장(JSONL/CSV)으로 데이터를 영구 저장하고, CRUD/검색/요약/입출력을 구현할 수 있다.
    => JSONL과 JSON의 차이점
    => 가장 큰 차이점은 데이터를 하나의 구조로 저장 -> json / JSON 객체를 한 줄에 저장 -> jsonl
    => JSON : 전체 데이터가 하나의 JSON 문서, 배열 안에 여러 객체를 담을 수 있음, 일반적으로 파일 전체를 읽고 JSON으로 파싱
    => JSONL : 한 줄마다 독립적인 JSON 값, 여러 줄을 하나의 배열로 감싸지 않음, 한 줄씩 읽고 처리하기 편리

    => csv(Comma-Separated Values)란?
    => 데이터를 표 형태로 저장하는 텍스트 파일 형식
    => 데이터를 표현할 떄 행과 열로 표현할 수 있고 다른 프로그램과 쉽게 주고 받을 수 있는 텍스트 파일 형식입니다.

3. yield 기반 제너레이터로 대용량 파일도 스트리밍 처리하는 이유와 동작 방식을 설명할 수 있다.
    => 함수가 yield 값을 하나 반환하면 함수 실행을 잠시 멈춘 뒤, 다음 값 요청하면 멈췄던 위치부터 다시 실행합니다.
    => next(이터레이터 함수) -> 값이 하나 반환됩니다.
    => 대량 데이터의 순차 처리가 용이해집니다.
    => yield 기반 제네레이터는 모든 데이터를 한꺼번에 메모리에 올리지 않고 필요한 시점에 데이터를 만들어 처리할 수 있습니다.
    => 일반적으로 for문을 순회해서 반복가능한 객체를 순회하는 것은 이미 메모리 상에 올라와 있어야 합니다.

4. 데코레이터로 공통 관심사(로그/예외/시간 측정) 를 분리한 구조와 이유를 설명할 수 있다.
    4-1. 데코레이터란?
        => 기존의 함수를 직접 수정하지 않고, 기존 함수에 새로운 기능을 추가하거나 실행 방식을 변경하는 방법입니다.
    4-2. 파이썬에서는 함수도 하나의 객체이며 함수를 인자로 전달할 수 있습니다. (hello() 실행 / hello 함수 객체)
    4-3. @wrapper
        def hello():
            print("안녕하세요!")

    def wrapper(func):
        def inner():
            print("함수 실행 시작")
            func()
            print("함수 실행 종료")

            return inner

        hello()
        => 데코레이터가 먼저 실행되고 hello 함수가 자동으로 인자로 들어가서 제어권을 얻습니다.
        => 원하는 순간에 실행될 수 있습니다.
        => @wrapper
            def hello() :
                print("안녕하세요")
        => hello = wrapper(hello) 위의 두개는 같은 동작을 합니다.
    
    4-4. def wrapper(func):
            def inner(*args, **kwargs):
                print("함수 실행 시작")

                result = func(*args, **kwargs)

                print("함수 실행 종료")

                return result

            return inner
        => wrapper(func)은 기존 함수를 전달받아서, 새로운 함수를 돌려주는 역할입니다.
        => inner(*args, **kwargs)은 실제로 호출될 때 로그를 출력하고 기존 함수를 실행하는 역할
        => inner는 기존의 함수를 받아서 처리하고 실행된 값을 돌려주는 것,
        => wrapper는 그 함수 포인터를 전달해주는 것
