1. add_mutually_exclusive_group()
    => export_group = parser.add_mutually_exclusive_group(required = True)
    => 이를 사용하면 export_group.add_argument에 해당되는 옵션이 동시에 사용될 수 없습니다.


2. 명령어 구조
    => python3 -m budget_app --out export --month (--from) --to
    => out은 필수 (파일 경로)
    => --month나 --from은 둘 중 하나만 써야 하지만 둘 중 하나는 필수로 들어가야 합니다.
    => -- to는 자율입니다.


3. if args.command == "export":
    => handle_export()를 실행합니다.


4. def handle_export(args, transaction_repository) -> int:
    4-1. args.month만 존재한다면 date.fromisoformat(args.month + "-01" )를 실행해서 검증합니다.
    4-2. 실패시 valueError 발생 -> 그에 따른 처리
    4-3. if parsed_month.strftime("%Y-%m") != args.month: -> yyyy-mm 형식인지 확인
        => 근데 4-1 검증이 yyyy-mm-dd라 불필요할 수 도 있습니다.
    4-4. 검증이 성공하면 date_from = args.month + "-01" / date_to = None으로 처리합니다.

    4-5. 만약 args.month가 없다면 else를 실행합니다.
    4-6.  if not args.date_from or not args.date_to:
        => args.date_from이나 args.date_to가 없다면 raise 발생시킵니다.
    4-7. date.fromisoformat(args.date_from) / date.fromisoformat(args.date_to) 하고 예외처리
    4-8. date_from > date_to를 사용해서 시작날짜는 종료 날짜보다 늦을 수 없다는 처리

    4-9. output_path = Path(args.out)로 출력 PATH 객체를 생성합니다.
    4-10. output_path.parent.mkdir(..)를 통해 파일 경로 상위에 폴더 생성
        => parents=True, (받아온 path에서 없는 상위 폴더도 함께 생성) / exist_ok=True, 있다면 넘어감처리
    4-11.  with output_path.open(..)
        => 이 떄 파일이 없으면 생성하고 존재하면 기존 내용을 비우고 쓰기 시작합니다.
        => encoding="utf-8-sig", -> 파일 시작 부분에 Byte Order Mark을 추가합니다.
        => 엑셀에서 csv 파일을 열 떄 한글이 깨지는 문제를 줄이는데 도움이 됩니다.
        => newline="" -> csv 파일을 작성할 떄 줄바꿈이 중복되는 문제를 방지하기 위해 권장되는 설정
    4-12. writer = csv.writer(file)
        => 파일에 CSV 형식으로 데이터를 기록할 수 있는 작성 객체(writer) 를 만듭니다.
    4-13.writer.writerow([ "date", "type", "category", "amount", "memo", "tags", ])
        => 값들을 리스트로 전달하면 CSV 규칙에 맞게 구분자와 줄바꿈을 처리해 줍니다.
        => 먼저 칼럼을 작성하는 것입니다.
    4-14. for transaction in transaction_repository.iter_transactions():
        => 하나씩 가져오고 규칙에 맞게 검증합니다.
    4-15.  writer.writerow([]) -> 규칙에 맞는 데이터를 씁니다.
    4-16. ",".join(transaction.tags or [])
        => ["점심", "회사"] -> "점심, 회사" 이렇게 변경해줄 수 있습니다.
    4-17. 완료되면 count+1
