    => 이를 가져와서 transactio.jsonl에 넣습니다.


1. if args.command == "import":
    => handle_import(args, transaction_service,)를 실행합니다.


2. def handle_import(args, transaction_service) -> int:
    2-1. input_path = Path(args.input_file) -> 명령어로 가져온 데이터를 경로 객체로 만듭니다.
    2-2. if not input_path.is_file(): -> 해당 경로에 실제 파일이 존재하면 True, 그렇지 않으면 False를 반환합니다.
    2-3. existing_transactions -> for - in - iterator를 통해 transaction에 존재하는 거래내역을 가져옵니다.
    
    2-4. with input_path.open(...) -> 파일을 엽니다.
    2-5. reader = csv.DictReader(file)
        => CSV 파일을 읽어서 각 행을 딕셔너리 형태로 제공하는 객체입니다.
        => DictReader는 첫 줄을 열 이름으로 사용합니다.
    2-6. if not reader.fieldnames or not required_columns.issubset(reader.fieldnames ):
        => reader.fieldnames은 CSV 파일의 첫 줄 열 이름 목록을 반환합니다. 
        => ["date", "type", "category", "amount", "memo" ] -> 이렇게 됩니다.
        => reader;fieldname가 없거나 비어 있기나 required_columns에 없다면 -> raise
        => issubset은 어떤 집합의 모든 원소가 다른 집합에 포함되어 있는지 검사하는 메서드입니다. -> 있으면 True, 없으면 False
    2-7. for row in reader:
        => 한 줄씩 읽습니다. -> 이 떄 필드 이름을 건너뛰고 읽습니다.
        => transaction_date = row["date"].strip() -> 이렇게 읽어서 가져옵니다.
        =>  memo = (row.get("memo") or "").strip() -> 메모가 없으면 빈 문자열
        => tags = [tag.strip() for tag in (row.get("tags") or "").split(",") if tag.strip() ]
            -> 가져온 tags 문자열을 ,로 나눠서 리스트로 만들고 하나 하나 요소를 strip해서 비어 있는지 확인하고 tag.strip으로 처리
        => transaction_key / tuple(tags), -> ["ㅁㅁ", "ㅁㅁ"] -> ("ㅁㅁ", "ㅁㅁ");

        =>  if transaction_key in existing_transactions:
                skipped += 1
                continue
            -> existing_transactions의 모든 데이터를 튜플로 -> 거기에 해당되면 skipped+1 그리고 다음으로 넘어갑니다.
        
        => transaction_service.add_transaction -> 새로운 거래는 저장합니다.
        => existing_transactions.add(transaction_key) -> 튜플에 추가됩니다. -> 저장된 거래도 중복 검사해야 합니다.
