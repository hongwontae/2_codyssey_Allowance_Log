1. ptyhon -m budget_app search --from --to --category --type --q --tag
    => 모든 옵션은 선택 사항입니다.
    => 모든 옵션을 주지 않으면 전체 리스트를 출력합니다.


2. if args.command == "search":
    => command가 search일 때 handle_search(..)를 실행합니다.


3. transactions = transaction_service.search_transactions(옵션값)


4. def search_transactions이 실행됩니다.
    4-1. 받아온 인자는 str | None 타입 힌트, default는 None입니다.
    4-2. 날짜를 먼저 검증합니다. date_from, date_to
        => for value in (date_from ,date_to) 튜플을 반복합니다.
        => if value is not None: 만약 value가 None이 아니라면
        => date.fromisoformat(value) 날짜 객체로 변환합니다. -> 올바른 형태의 문자열이 아니라면 valueError
        => date.fromisoformat은 2026-01-01 같은 형태여야 제대로 변환합니다.
    4-3. 시작날짜와 종료날짜를 비교해서 시작 날짜가 더 늦는다면 raise
    4-4. income, expense도 검증
    4-5. for transaction in self.repository.iter_transactions():
        => 파일에서 하나씩 가져옵니다.
        => date_from, date_to에 적합한 데이터인지 확인 (continue 사용)
        => if category and transaction.category != category: 카테고리 확인
        => transaction_type and transaction.type != transaction_type 
            -> transaction_type이 존재하는지, 그리고 일치하는지 확인합니다.
        => if keyword and keyword.casefold() not in transaction.memo.casefold():
            -> in 연산자 문자열을 사용하면 부분만 맞아도 true
            -> 만약 가져온 메모에서 일치하는게 없다면 continue
        => 태그 검사도 합니다.
    4-6. results.append(transaction) -> 그리고 일치하는게 있다면 하나씩 추가합니다.
    4-7. results.sort( key=lambda item: (item.date, item.id), reverse=True, )
        => results.sort는 리스트를 정렬하는 메서드입니다.
        => key는 무엇을 기준으로 정렬할지 지정합니다.
        => key=lambda item: (item.date, item.id) -> date를 기준으로 정렬하고 우선순위가 같다면 id 사용
        => reverse=True, -> 역순으로 -> date를 오름차순으로 정렬
    4-8. 그 값을 반환합니다.
